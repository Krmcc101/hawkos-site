# HawkOS Website

Before publishing:
1. Replace hawkossupport@gmail.com everywhere with your chosen public support email.
2. Deploy this folder to a public HTTPS host.
3. Use:
   - /support.html as the App Store Support URL
   - /privacy.html as the Privacy Policy URL

Easy hosting options: GitHub Pages, Cloudflare Pages, Netlify, or EAS Hosting.
